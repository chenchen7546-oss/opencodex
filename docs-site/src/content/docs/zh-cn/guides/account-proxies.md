本定制分支在管理界面增加了**代理管理**。代理、绑定和统计保存在独立数据库中，
不修改原仓库的账号文件格式。这里描述的是定制功能，不代表上游 2.94.0 原版已提供这些能力。

## 添加代理并绑定账号

1. 进入 **代理管理 → 代理列表 → 添加代理**，填写协议、地址、端口和认证信息。
2. HTTP、HTTPS、SOCKS5、SOCKS5h 可直接使用。自建 VPS 需要先运行代理服务；
   商业代理按卖家提供的协议填写。一个 IP 地址本身不等于可用代理。
3. 点击**检测出口**，通过代理访问 `api.ipify.org`。结果是当前出口 IP 和检测耗时，
   不代表所有提供商都接受这个出口。
4. 在**账号绑定**中勾选账号，选择代理，点击**分配给选中账号**。可以跨提供商批量选择。

`127.0.0.1` 指 OpenCodex 所在服务器。美国 VPS 上的 DSH 需要国内出口时，
必须接入具有相应国内网络出口的代理；填写美国 VPS 自己的 IP 不会改变出口地区。

账号可选择继承、直连或指定代理。继承先使用**提供商默认代理（含新账号登录）**，
再使用原有的提供商／全局代理设置。第一次导入或登录区域受限账号前，先给对应提供商设置默认代理。
服务器发起的验证、令牌刷新、额度查询和模型请求会使用对应账号的绑定。
OAuth 在浏览器打开的登录页面仍由浏览器自身的网络决定。

代理停用、缺失或连接失败会导致请求失败，不会自动直连。删除代理前需要先解除或调整绑定。
轮换账号时按实际发送的凭据重新选择出口。Codex WebSocket 和 Cursor 的请求在需要时
使用可传递代理设置的 HTTP/SSE 或 HTTP/1.1 路径。

外部 Claude CLI、CodeBuddy、Qoder 进程沿用自身的网络设置，账号绑定不控制其模型连接，
也不会因此阻止它们运行。不透明的自定义请求执行器和改写到本地旁路服务的插件，在明确绑定代理时
会拒绝请求。客户端临时转发的未知凭据不会自动成为受管账号。

## 节点与订阅

**批量导入**支持代理 URL、SS／VMess／VLESS／Reality／Trojan／Hysteria2／TUIC／AnyTLS
常见链接、Base64 链接列表，以及 Clash 的 `proxies` YAML／JSON 列表。
SSR、Hysteria、WireGuard、SSH 等使用节点定义导入。未支持的字段会明确报错；
不会安装订阅里的任意完整配置、脚本或控制接口。

高级节点需要另外在服务器安装 **Mihomo**，把可执行文件路径放入 `OPENCODEX_PROXY_CORE`，
或确保 PATH 中有 `mihomo`，再重启服务。HTTP／HTTPS／SOCKS5 无需安装内核。
每个 OpenCodex 进程按需启动一个共享内核，本地入口有认证且只监听回环地址。
首次使用会验证配置并启动内核，建议先检测出口再绑定。配置变更遇到未结束的流式请求时，
新请求会暂时报 `proxy_core_busy`，待原请求结束后重试。

**订阅管理**可保存订阅地址、分组以及下载订阅时使用的代理。点击**更新节点**手动同步，
没有后台定时拉取。相同订阅节点名称保留 ID 和账号绑定，消失的节点停用，重名节点使本次更新失败。
改名视为新节点。移除订阅源会保留已导入的代理。
保存后的订阅地址和节点密码不通过查询接口返回；编辑代理时密码留空表示保留原值。

## 流量与资源

统计包括提交的上传正文、已读取的下载正文、请求数和失败数；重试和出口检测也计入。
这是**应用层统计**，提交失败也可能计入上传量，不含 HTTP／TLS／代理握手开销、
其他软件流量和网络压缩差异，不能作为运营商账单。取消流式请求会记录已读取部分。

每日与每月边界使用 UTC。页面展示前 500 条明细，CSV 最多 10,000 条；汇总不受明细条数限制。
月度限额可提醒或阻止新请求，已开始的流和并发请求可能使最终流量超出限额。

默认保留 90 天、检测并发 2、统计每 15 秒落盘；计数器有内存上限，使用 SQLite，不需要 Redis
或独立数据库服务。保留期不足一个月时仍保留当月数据，确保月度限额一致。
异常退出可能丢失尚未落盘的计数；磁盘写入失败会显示统计不完整。

1 GB 服务器建议先使用 HTTP／SOCKS 代理并降低模型请求并发，前端在别处构建。
原项目和可选内核仍需要内存，必须按实际运行负载评估，不能仅按代理模块开销判断容量。

停止服务后，将 `$OPENCODEX_HOME/proxy-manager/` 与应用其他状态一起备份。
目录含敏感信息，不要提交到 Git。在线备份需使用 SQLite 备份机制，不能在 WAL 活跃时只复制数据库主文件。
更新应合并上游代码后重新构建，直接安装官方发行包可能覆盖定制功能。

## 定制 Docker Compose 方案

定制镜像已集成校验固定 SHA-256 的 Mihomo 1.19.33，并设置可执行文件路径，无需另外安装或开放内核端口。
内核启动后先完成私有回环 HTTP 检测，再接收模型请求；仅端口开放不代表可转发。此检测不使用提供商凭据或上游流量。
在开发机运行 `docker compose -f deploy/compose.build.yaml build hub`，再执行
`bun scripts/custom/docker-smoke.ts` 与 `bun scripts/custom/export-image.ts` 完成验收和打包。
导出包含 Linux amd64 镜像、独立运行配置、环境变量示例、校验文件和部署说明，不导出账号或数据卷。
服务器导入镜像后，在一次性 Compose 容器中执行 `bun docker/custom/init.ts`，再启动 hub 服务。
更新时保持 Compose 项目名一致以复用两个状态卷，正常更新不要删除卷。

默认内存上限 640 MiB、内存加 swap 总额度 896 MiB，启用日志轮转且只监听本机回环地址；限制不代表容量保证。
初始 OpenAI 并发为 1，新增提供商需单独降低并发，升级不会覆盖已有卷的配置。
通过 SSH 隧道访问，管理页面用管理员令牌，模型客户端用另一份服务令牌。
完整步骤在仓库及导出包的 `deploy/README.zh-CN.md`（导出后位于包根目录）；构建配置保留在源码中，上游根容器方案不变。

OAuth 复制链接在 Clipboard API 不可用时，会在当前原生弹窗内执行回退复制；两种方式均被浏览器拒绝时，
页面提供可全选的完整链接框，便于手动复制。

订阅导入支持 Shadowsocks 内置 obfs、v2ray-plugin、gost-plugin、shadow-tls 参数、TUIC 请求超时和 AnyTLS 空闲会话参数；旧格式的顶层 brutal 参数归入 smux，空值 VLESS flow 自动省略。仍不接受外部可执行插件和凭据文件路径。重复添加同一订阅链接会提示已存在，不再生成第二条记录。
账号绑定优先显示别名、服务商返回的邮箱，内部 ID 缩短后放在次要位置。服务商未提供可识别信息时明确显示未命名，可直接点击该行的编辑别名。别名与提供商账号页共用，不改变代理绑定；原生 Codex 主账号保留上游不可编辑别名的规则。

## 登录验证与代理切换

新增 Codex 账号时，服务端 OAuth、额度查询和模型验证使用 OpenAI 提供商默认代理。已有账号重新认证、后台刷新和验证使用账号独立绑定。网络验证失败会提示检查对应代理，不会仅凭网络失败判断令牌过期。

保存绑定后，后续服务端请求（包括重试、令牌刷新和额度查询）使用新代理，无需重启或重新登录。正在返回内容的模型流使用原连接完成，下一次请求切换到新代理。绑定的代理停用或故障时，请求会报错，不会偷偷直连。已有节点之间切换不会中断流；修改高级节点连接参数时，可能需要等待现有流完成后再更新内核。浏览器打开的登录网页仍使用浏览器所在设备的网络。

Codex 登录会先保存通用 ChatGPT OAuth 中间记录，再写入正式 OpenAI 账号池。代理管理仅展示正式账号；除非单独配置了 ChatGPT 提供商，否则隐藏中间记录，但不删除凭据。不会按邮箱合并其他提供商账号或不同账号池条目。历史上已给中间记录单独绑定代理的，保留为可解除的旧绑定。
